## Modifier le site

**Tester en local**

```bash
git clone https://github.com/cyrilhermantin-create/cv-cyril-hermantin-Economiste-de-la-construction.git
cd cv-cyril-hermantin-Economiste-de-la-construction
python -m http.server 8000
```

Ouvrir ensuite <http://localhost:8000> dans le navigateur.

**Publier**

```bash
git add .
git commit -m "Mise à jour du CV"
git push origin main
```

GitHub Pages doit être configuré sur la branche `main`, dossier `/ (root)` (Settings → Pages). Si le nom du dépôt change, mettre à jour l'adresse encodée dans le QR code de `index.html`.
